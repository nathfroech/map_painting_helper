# Code Review

- Keep changes focused: minor unrelated fixes are fine if they're small or touch the same areas, but
  large unrelated changes are not.
- Consider if additional changes fit the PR's theme and would be useful.
- Check if code changes need updates to `README.md`, docs, or `AGENTS.md`.
- Don't run linters, type checking, or tests during review — CI handles that.
- Never make code changes during review. Describe necessary changes in the output only.
